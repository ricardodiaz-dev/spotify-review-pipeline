Golden 50 — human labels
Label definitions (GRADING_CONTRACT.md)

topic: access (login/account) · usability (navigation, controls, layout, queue/playlist, shuffle/skip, ads) · playback (failures, crashes, lag, connection, audio, devices, battery) · downloads (offline/saved) · catalog (missing content, search, recs, lyrics, podcasts) · billing (price, charges, subs, paywalls, premium-only controls) · support · other (general praise/criticism, unrelated). Highest-severity problem; tie → first mentioned; praise → first specific praised feature.
intent precedence: cancellation > complaint > request > praise > unclear (bare boycott slogans = unclear).
severity: 1 none/praise/unclear/request · 2 generic criticism/annoyance · 3 degraded, some use remains · 4 core task blocked · 5 explicit serious financial/privacy/data harm.
sentiment −1…1. evidence_quote: exact substring. Mark ambiguous + list other acceptable labels if several are defensible.
